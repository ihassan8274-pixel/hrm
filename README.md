# نظام إدارة الرواتب المتكامل (HR & Payroll System)

هذا النظام مصمم لمساعدة الشركات والمؤسسات على إدارة شؤون الموظفين، الرواتب، الحضور والانصراف، والعهد المالية بشكل آلي ودقيق.

## 🚀 النشر على خادم مركزي

يعمل الخادم على PostgreSQL، ويدخل الموظفون من المتصفح عبر عنوان واحد. لا يحتاج كل جهاز موظف إلى تثبيت قاعدة بيانات أو تشغيل خادم محلي.

## 🛠️ تشغيل الخادم أو التطوير محلياً

إذا كنت تفضل التشغيل يدوياً أو تعمل على نظام (Mac/Linux):

1.  **إعداد PostgreSQL**: جهّز قاعدة مخصصة للنظام، ثم انسخ `.env.example` إلى `.env` واضبط `DATABASE_URL` و`PGSCHEMA` و`JWT_SECRET`.
2.  **تثبيت المكتبات**:
    ```bash
    npm install
    ```
3.  **بناء الواجهة والخادم**:
    ```bash
    npm run build
    ```
4.  **تشغيل الخادم**:
    ```bash
    npm start
    ```
5.  **الوصول للنظام**: افتح `http://localhost:3000` أو عنوان الخادم من أجهزة الموظفين. استخدم HTTPS عند تشغيل تسجيل الحضور ببصمة الهاتف.

### النشر باستخدام Docker Compose

اضبط متغيرات PostgreSQL وكلمة مرور JWT قوية في `.env`. اجعل مضيف `DATABASE_URL` هو `db`. للنشر الجديد شغّل `docker compose up -d --build`. يحتفظ PostgreSQL ببياناته في volume مستقل، ويستمع التطبيق على المنفذ المحدد في `APP_PORT`.

تم نقل بيانات النظام إلى PostgreSQL والتحقق من تطابق محتوى الجداول. التشغيل الجديد يستخدم PostgreSQL فقط، ويحفظ البيانات في volume مستقل.

## 💻 أدوات ويندوز المحلية

ملفات التشغيل والمثبّت تشغّل نسخة خادم محلية على جهاز واحد. للنشر المشترك، شغّل التطبيق على الخادم المركزي واجعل بقية الأجهزة تفتح عنوانه من المتصفح.

### 1️⃣ كيفية بناء ملف التثبيت الموحد (EXE):
ببساطة، انقر بزر الفأرة الأيمن على ملف `build-installer.ps1` واختر **Run with PowerShell** (تشغيل باستخدام PowerShell).
* ستقوم هذه الأداة تلقائياً بـ:
  * تحويل شعار النظام الرسمي المولد إلى ملف أيقونة ويندوز ذو دقة عالية (`app-icon.ico`).
  * تجميع وبناء ملفات النظام بأحدث إصدار.
  * التحقق من وجود مجمع الحزم `Inno Setup` وتثبيته تلقائياً وبأمان عبر متجر تطبيقات مايكروسوفت (Winget) إذا لم يكن موجوداً.
  * توليد ملف التثبيت الاحترافي في ثوانٍ معدودة داخل مجلد: `InstallerOutput\SalarySystemSetup.exe`.

### 2️⃣ مميزات ملف التثبيت المولد (SalarySystemSetup.exe):
عند مشاركة أو تثبيت هذا الملف على أي جهاز كمبيوتر يعمل بنظام ويندوز:
* **تجهيز تلقائي وخفي**: يقوم المثبت تلقائياً بتنزيل وتثبيت جميع المتطلبات وربط مكتبات البرمجية (`npm install`) وبناء الواجهة (`npm run build`) **أثناء شريط تقدم التثبيت** دون أي تداخل أو شاشات سوداء مزعجة.
* **أيقونة سطح المكتب والبدء**: يولد اختصاراً برسمة الشعار الرسمي على سطح المكتب وقائمة ابدأ باسم **"نظام إدارة الرواتب"**.
* **الخادم المركزي**: يفتح المستخدمون النظام من عنوان الخادم؛ بيانات جميع الأجهزة تحفظ في PostgreSQL على الخادم ولا يعتمد التشغيل اليومي على قاعدة محلية في جهاز الموظف.

### 3️⃣ تشغيل وإيقاف النظام (بدون نوافذ أوامر مزعجة):
* **التشغيل الصامت**: عند فتح التطبيق من أيقونة سطح المكتب (أو بتشغيل ملف `launcher.vbs`)، سيعمل خادم النظام بشكل **صامت تماماً في الخلفية (Silent Mode)** دون إبقاء أي نافذة أوامر سوداء مفتوحة مع فتح المتصفح تلقائياً على النظام.
* **إيقاف النظام بلمسة واحدة**: إذا رغبت في إيقاف تشغيل الخادم في أي وقت، ببساطة قم بتشغيل ملف `stop-app.bat` وسيقوم تلقائياً بالبحث عن الخادم وإغلاقه بأمان.

## 📂 مكان حفظ البيانات
تُحفظ بيانات التشغيل في PostgreSQL. النسخ اليومية التي ينشئها الخادم تُكتب بصيغة JSON داخل مجلد `backups/` على الخادم، ويمكن معرفة تاريخ آخر نسخة عبر `/api/backup/status`.

> **نسخ احتياطي تلقائي:** يقوم الخادم بإنشاء نسخة يومية باسم `payroll-YYYY-MM-DD.json`. خزّن النسخ في مكان آمن، وأضف نسخًا خارج الخادم ضمن خطة الاستعادة.

## 🏢 حضور الفروع وهاتف الفرع (Phone Kiosk)

كل فرع يُربط به **هاتف واحد** يسجّل حضور وانصراف موظفيه ببصمة الوجه أو بصمة الإصبع.

### خطوات التهيئة
1. من **الفروع والمواقع**: أدخل إحداثيات الفرع (Latitude / Longitude) ونطاق السياج الجغرافي (مثال 150 متراً).
2. من **جهاز الحضور (Kiosk)**: سجّل الجهاز واختر الفرع — سيظهر **رقم تفعيل من 6 أرقام**.
3. افتح رابط الفرع `https://<server>/kiosk/<device_token>` على هاتف الفرع **وهو داخل الموقع**، ثم أدخل رقم التفعيل.
4. سجّل بصمة كل موظف مرة واحدة من نفس الهاتف (بصمة الوجه/الإصبع) أو من بطاقة الموظف.

### الضوابط الأمنية
- لا يتم تفعيل الهاتف إلا **داخل نطاق الفرع**؛ أي محاولة من موقع آخر تُرفض ويُسجَّل الحدث.
- بعد التفعيل لا يعمل الرابط إلا من **نفس الهاتف**، و`إعادة ربط هاتف جديد` متاحة للإدارة فقط.
- لا يُقبل تسجيل الحضور/الانصراف **بدون موقع GPS صالح داخل نطاق الفرع**.
- الموظف يُقبل تسجيله فقط على **هاتف فرعه** المسجل في بياناته.
- كل محاولات الخروج عن النطاق أو رمز التفاعل الخاطئ تُوثَّق في سجل أمني ويظهر ملخصها في شاشة **حضور الفروع الآن**.

### متغيرات البيئة
| المتغير | الوصف |
|---------|-------|
| `PORT` | منفذ التشغيل (افتراضي 8090) |
| `SSL_KEY_PATH` | مسار مفتاح SSL لتفعيل HTTPS — **مطلوب لبصمة الهاتف** |
| `SSL_CERT_PATH` | مسار شهادة SSL |
| `WEBAUTHN_RP_ID` | نطاق التحقق للبصمة (اسم المضيف بدون منفذ) |
| `JWT_SECRET` | مفتاح توقيع الجلسات (غيّره في الإنتاج) |

> بصمة الوجه/الإصبع في المتصفح لا تعمل إلا عبر **HTTPS** أو `localhost`. عند ضبط مساري الشهادة يعمل الخادم تلقائياً بنظام HTTPS.

## 📅 دورة المسير الشهري

1. **مزامنة الحضور واحتساب المسير** من شاشة الرواتب — يحسب الغياب والتأخير والعمل الإضافي آلياً من سجلات البصمة.
2. مراجعة المسير (نقدي / بنكي / GOSI) ثم **إقفال واعتماد المسير** — يمنع أي إعادة احتساب بعد الإقفال.
3. تصدير **ملف مدد (WPS SIF)** ويشمل الجزء البنكي فقط، إضافة إلى كشف Excel بالتفصيل النقدي والبنكي.

## 🔐 الأدوار والصلاحيات

| الدور | الصلاحيات |
|-------|-----------|
| `admin` | كل الشاشات + إقفال المسير + ربط الأجهزة |
| `hr_manager` | كل شاشات الموارد البشرية والرواتب |
| `finance` | المسير، WPS، السلف، المكافآت، التقارير، إقفال المسير |
| `branch_manager` | الحضور، هاتف الفرع، الإجازات، صندوق الاعتماد، التنبيهات |
| `employee_ess` | بوابة الخدمة الذاتية (سجله فقط) |

كل مسارات `/api` محمية بجلسة صالح — ما عدا تسجيل الدخول ومسارات هاتف الفرع والبصمة.

**صندوق اعتماد المدير من الجوال:** افتح `/approvals` لاعتماد الإجازات وطلبات سلاسل الاعتماد من الهاتف.

## 🆕 الميزات الجديدة (الإصدار المحدث)

### 1. جهاز الحضور والانصراف (Kiosk) بالموقع الجغرافي 📍
* تسجيل أجهزة حضور ثابتة وربطها بفرع معين (`attendance_devices`).
* التحقق الجغرافي: الجهاز يجب أن يكون داخل نطاق الفرع (Geofence) وإلا يُمنع التسجيل.
* تسجيل دخول/خروج مع حفظ الإحداثيات وطريقة التسجيل (وجه/بصمة/يدوي).
* كشف التأخير والغياب لكل فرع.
* ضبط إحداثيات كل فرع وشعاع النطاق من شاشة الفروع.

### 2. المصادقة البيومترية 👤
* بصمة الوجه وبصمة الإصبع (WebAuthn/FIDO2) عند جهاز الفرع.
* صورة/قالب مرجعي لكل موظف (`face_template`).
* دعم قارئ بصمة مادي (ZKTeco) كخيار متقدم.

### 3. ملف الموظف والوثائق 📁
* صفحة ملف لكل موظف تعرض كل بياناته (الوظيفة، الفرع، الجنسية، الهاتف، الإقامة، الجواز، الشهادة الصحية).
* معرض صور/ملفات للوثائق (جواز، إقامة، شهادة صحية، عقد) مع رفع وعرض وحذف.
* جدول `employee_documents`.

### 4. مركز التنبيهات ⏰
* تنبيه قرب انتهاء الإقامة (30 يوم).
* تنبيه قرب انتهاء الشهادة الصحية (30 يوم).
* تنبيه قرب انتهاء جواز السفر (180 يوم).
* تنبيه مخالفة مسمى الإقامة للوظيفة الفعلية.
* تنبيه التأخير والغياب.

### 5. نقل الموظف بين الفروع 🔄
* سجل نقل كامل (`employee_transfers`).
* عند النقل يتغير الموقع الجغرافي المرتبط بالموظف إلى الفرع الجديد.
* توزيع تكلفة الرواتب حسب أيام الحضور الفعلية في كل فرع.

### 6. تقسيم الرواتب نقدي / بنكي 💵🏦
* تحديد طريقة الدفع لكل موظف (نقدي/بنكي) من نموذج الموظف.
* تقرير إجمالي الشركة: نقدي وبنكي.

### 7. تقارير الرواتب 📊
* كشف رواتب الموظف (إجمالي + خصومات).
* تقرير رواتب الفروع (التكلفة الفعلية حسب أيام الحضور).
* إجمالي الشركة نقدي/بنكي.

## 🔒 ملاحظة أمنية مهمة (للرفع على الإنترنت)
